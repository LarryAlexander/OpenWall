# Milestone 3 household trial

This checklist is the human acceptance step for the local Milestone 3 slice.
Automated tests prove the implementation and browser behavior; they do not
prove that a real household wants to use the utilities for a week.

## Trial setup

- Use one wall-sized display and one tablet or phone on the same household
  network. No network connection between them is required for this milestone;
  each browser remains local.
- Start with a fresh backup and record the browser, device, viewport, and date.
- Keep household data fictional or use a household that has explicitly agreed
  to the trial.

## During one school week

- Plan at least three timed or all-day items in Week, including one school
  closure or other exception.
- Create one recurring routine, assign it, complete one occurrence, and skip a
  different occurrence without deleting the routine.
- Use at least two list types, complete list items, remove one item, and add a
  planned meal's ingredients to the grocery list.
- Set focus and sleep windows on the display device and confirm the board's
  behavior during each window.
- Select at least two local photos, confirm rotation, and note whether storage
  use or image handling is comfortable.
- Reload once offline and confirm the saved household still opens.

## Record before opening Milestone 4

- Which two utilities were used repeatedly?
- Did Today remain glanceable from the normal viewing distance?
- Did any routine, list, meal, or photo action feel confusing or unsafe?
- Were the wall and handheld layouts readable and touchable?
- Did storage, browser permissions, or offline behavior cause a problem?
- What change should be made before designing same-home Wi-Fi sync?

Do not describe Milestone 3 as household-validated until these observations
are recorded and reviewed.
